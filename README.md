# AI Study Assistant

A simple Streamlit-based study assistant that extracts text from a PDF lecture, builds semantic embeddings with SentenceTransformers, retrieves relevant content via FAISS, and uses an LLM through `ollama` to answer student questions.

## Features

- Upload a PDF and automatically extract its text.
- Chunk the extracted content into smaller passages.
- Create embeddings with `all-MiniLM-L6-v2`.
- Use FAISS for semantic retrieval of relevant passages.
- Ask questions about the PDF and receive answers generated by an LLM.

## Installation

1. Create and activate a Python virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Install dependencies:

```powershell
pip install -r requirements.txt
```

3. Make sure an Ollama server is installed and available if you want to use the `ollama` integration.

## Usage

1. Run the app:

```powershell
streamlit run app.py
```

2. Open the URL shown in the Streamlit output (typically `http://localhost:8501`).
3. Upload your lecture PDF using the file uploader.
4. Type a question about the PDF content.
5. Inspect the generated answer and chat history.

## Environment

- The app imports `dotenv` and loads `.env` if present, but the current code does not require any specific environment variables.
- If you switch to another LLM provider, add the corresponding API key or configuration to `.env` and update `app.py`.

## Dependencies

- `streamlit`
- `pypdf`
- `sentence_transformers`
- `faiss-cpu`
- `python-dotenv`
- `ollama`

## Notes

- The app currently relies on `ollama.chat` with model `llama3`.
- If your PDF is scanned or image-only, text extraction may fail: use OCR first.
- The current chunking approach is fixed-size and may split sentences; this can be improved later.
- The `requirements.txt` includes `openai`, but the current app does not use it.
